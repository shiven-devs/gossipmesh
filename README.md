# GossipMesh

Decentralized cluster-membership + failure-detection service (gossip protocol) on Docker + Kubernetes.

> README Phase 10 mein poora likha jaayega. Abhi ye starter pack hai.

## Is folder mein kya hai

| Path | Kaam |
|---|---|
| `CLAUDE.md` | Claude Code ke liye rules (har session mein auto-read) |
| `docs/PLAN.md` | Poora plan: architecture, protocol, phases 0 se 10 |
| `prompts/01-kickoff.md` | Pehle session ka prompt |
| `prompts/02-phase-template.md` | Har agle phase ka prompt + extra lines |
| `prompts/03-helper-prompts.md` | "Samajh nahi aaya" aur quiz prompts |
| `legacy/` | Tumhara tested tutorial code (reference) |
| `docs/learning-log.md`, `docs/design-decisions.md` | Khud likhne ke liye |

## Shuru kaise karein

1. Ye folder `gossipmesh/` naam se WSL (Ubuntu) ke andar rakho, `git init` karo.
2. Us folder mein terminal kholo, `claude` chalao.
3. `prompts/01-kickoff.md` ka text paste karo.
